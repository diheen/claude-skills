# claude-skills

Custom Claude Code skills.

## Instalação

Copie a pasta da skill desejada para `~\.claude\skills\`:

```
~\.claude\skills\
  senior\
    SKILL.md
```

## Skills disponíveis

### `/senior`

Pair programming com modo de ensino. Fluxo: interroga → constrói → ensina → desafia.

Use quando quiser construir algo e entender o porquê das decisões, não só receber código.
